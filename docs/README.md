# 🎬 Web-Video Platform

**A modern, fast, single-page video platform**  
Inspired by **Netflix**, **YouTube**, **Instagram** + **OnlyFans**, **Pornhub**

---

## ✨ Core Idea
One app.  
Multiple content styles.  
Zero page reloads.

## 🚀 Goals
- Fast load times
- Smooth navigation
- Scalable structure
- Mobile-friendly design

## 🧭 Layout
- 📌 **Left Sidebar**
  - Home
  - Explore (3-column feed)
  - Messages
- 🖥️ **Dynamic Main View**
  - Videos
  - Shorts
  - Feeds
  - Profiles

---

## ⚙️ Tech Stack
- ⚛️ React
- ⚡ Vite
- 🎨 CSS / Tailwind
- 🧠 Component-based UI
- 🔄 SPA routing

---

## 🛠️ Setup & Run

### 📦 Requirements
- Node.js (LTS recommended)
- npm (comes with Node)

### ⚡ Test Project
In root folder:
```bash
npm install
npm run dev
```

For production:
```bash
npm run build
```

Visit:
[localhost:5173](localhost:5173)
